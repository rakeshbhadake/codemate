# Codemate - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Create Your Account (30 seconds)

1. Click **"Don't have an account? Register"**
2. Fill in:
   - Full Name: `Your Name`
   - Email: `your.email@example.com`
   - Password: `password123` (minimum 6 characters)
   - Confirm Password: `password123`
3. Click **"Create Account"**
4. You'll be automatically logged in!

### Step 2: Set Up Your Profile (2 minutes)

1. Click **"Profile"** in the navigation bar
2. Fill in your information:
   - **Bio**: Tell others about yourself
   - **Location**: Your city/country or "Remote"
   - **Availability**: Select your current status
   - **Skills**: Add your coding skills (e.g., React, Python, JavaScript)
     - Type a skill and press Enter or click +
     - Add 3-5 skills for best matching results
3. Click **"Save Changes"**

### Step 3: Explore the Platform (2 minutes)

#### Dashboard
- View your profile summary
- See your stats (followers, following, skills)
- Quick links to main features

#### Discover
- Browse all developers on the platform
- Use filters to find specific matches:
  - Location
  - Availability
  - Required skills
- Try **AI-Powered Search**:
  - Type: "Find me a React developer for a startup"
  - Click "AI-Powered Search"
- **Follow** developers you want to connect with

#### Events
- See hackathon and coding event announcements
- **Create an Event**:
  - Click "Create Event / Hackathon Post"
  - Fill in title, description, date
  - Add location and event link
  - Specify required skills
  - Post to your feed
- **Engage**: Like and comment on events

#### Messages
- Real-time one-on-one chat
- Click "Message" on a user card to start chatting
- Messages update automatically every 3 seconds

#### AI Chat
- Go to Discover > AI Chat tab
- Ask in natural language:
  - "I need a Python developer for machine learning"
  - "Find me someone who knows React and Node.js"
  - "Looking for a hackathon partner in New York"

## 🎯 Common Use Cases

### Finding a Hackathon Partner

1. Go to **Discover**
2. Set filters:
   - Location: Select your city or "Remote"
   - Skills: Add hackathon-relevant skills
3. Click **AI-Powered Search** with query:
   - "Looking for a hackathon partner this weekend"
4. **Follow** potential partners
5. Click **Message** to start conversation

### Creating a Hackathon Event

1. Go to **Events**
2. Click **"Create Event / Hackathon Post"**
3. Fill in details:
   ```
   Title: Annual Tech Hackathon 2025
   Description: 48-hour hackathon focused on AI and sustainability
   Date & Time: Select date and time
   Location: San Francisco or Online
   Event Link: https://hackathon-website.com
   Required Skills: JavaScript, Python, React
   ```
4. Click **"Create Event"**
5. Share the event ID with participants

### Networking with Developers

1. Complete your profile with detailed bio and skills
2. Go to **Discover** and browse developers
3. **Follow** 5-10 developers with shared interests
4. Engage with their posts in **Events** feed
5. Send **Messages** to start conversations
6. Build your network organically

## ❓ FAQ

**Q: Do I need to pay?**
A: No, Codemate is free to use!

**Q: How do AI features work?**
A: We use Google Gemini API for semantic matching and chatbot responses.

**Q: Are messages private?**
A: Yes, only you and the recipient can see your messages.

**Q: Can I delete my account?**
A: Contact support to delete your account and data.

**Q: How do I report a user?**
A: Use the reporting feature (coming soon) or contact support.

**Q: Can I use this for commercial projects?**
A: Yes, find partners for any type of coding project!

**Q: Is my data secure?**
A: We use Supabase for secure data storage with JWT authentication.

**Q: How often do messages update?**
A: Messages refresh automatically every 3 seconds.

**Q: What if I forget my password?**
A: Password reset feature is coming soon. Contact support for help.

**Q: Can I connect my GitHub?**
A: GitHub integration is planned for a future update!
